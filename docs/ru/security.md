# Безопасность

[Назад](architecture.md)

| Область | Покрытие |
|---|---|
| Хранение паролей | Многопроходное хеширование, необратимое при компрометации базы |
| Шифрование данных | Чувствительные данные зашифрованы и подписаны |
| Отображение данных | Номера счетов и карт маскируются в интерфейсе |
| Транспорт | HTTPS/TLS для всех соединений между клиентом и сервисами |
| Секреты | Хранятся вне кода, через переменные окружения |
| SQL-инъекции | Запросы к базе строятся через ORM, без сырого SQL |
| XSS | Вывод на страницы экранируется на уровне UI-фреймворка |
| CSRF | Защита от подделки межсайтовых запросов на уровне фреймворка |
| CORS | Запросы без ожидаемого источника отклоняются |
| Заголовки браузера | Ограничение встраивания в сторонние страницы, доступа к камере и микрофону, контроль передачи referrer |
| Авторизация | Доступ по умолчанию закрыт, публичные страницы и админский уровень доступа выделены явно |
| Доступ к чужим данным | Проверка владельца ресурса на каждом запросе, унифицированный ответ при отказе |
| Целостность операций | Бизнес-операции с несколькими изменениями данных выполняются в транзакциях |
| Тайминг-атаки | Постоянное время ответа на чувствительных эндпоинтах |
| Перечисление аккаунтов | Одинаковый ответ независимо от существования аккаунта |
| Размер входящих данных | Лимиты на загружаемые файлы и скрипты |
| Изоляция скриптов | Урезанное окружение выполнения, лимит по времени, принудительное прерывание при превышении |
| Сессии в браузере | Независимый механизм на серверных cookie |
| Сессии в MAUI-клиентах | Независимый механизм на защищенном хранилище устройства |
| Смена пароля | Отзыв всех активных сессий на всех устройствах |
| Двухфакторная аутентификация | TOTP с резервными кодами восстановления |
| Надежность пароля | Проверка на этапе регистрации, слабые пароли отклоняются |
| Защита от перебора | Ограничение частоты запросов на уровне API |
| Защита от подбора учетных данных | Отдельный механизм для чувствительных операций |
| Устойчивость сервера | Контроль количества одновременных подключений |
| Аудит | Отдельное логирование входов, регистрации, восстановления доступа и смены данных аккаунта |
| Логи | Не содержат чувствительных данных сверх минимальных идентификаторов |
| Разделение логики | Чувствительная логика существует только на сервере |
| Контроль данных | Пользователь может экспортировать или полностью удалить свои данные |
